# web — фронтенд «Полилога» (M2)

Стек: React + Vite + TypeScript (doc 01 §4.2), графики — Recharts, граф Customer 360 — React Flow.

Экраны (doc 08 §3–4):
- Дашборд РОПа: риск-борд, командные тренды, лидерборд по критериям таксономии
- Список звонков + экран звонка (аудио ↔ транскрипт, скор-карта, SHAP-факторы)
- Вкладка «Аналитика компании» (граф телефонов, лента инсайтов)
- Конструктор рубрик, словарь, коннекторы, eval/labels, админка

Статус: не начат (после стабилизации API M1). Сейчас API доступен через OpenAPI
на `http://localhost:8000/docs`.
