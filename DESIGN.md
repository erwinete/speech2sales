# DESIGN.md — визуальная система «Полилога» (ТЗ v6.0)

**Направление:** Quiet Minimalist Brutalism (тихий минималистичный брутализм) —
интерфейс строится как чертёжный лист / приборная панель с открытой
1-пиксельной структурной сеткой, без теней, скруглений и яркого контраста.

## 1. Правила геометрии

- **Открытая волосяная сетка** — вместо «парящих» карточек: панели смыкаются
  без зазоров, разделены линиями `1px solid var(--line-struct)`.
- **Прямые углы** — `border-radius: 0` глобально (глобальный сброс в
  `theme.css`); интерактивные элементы могут иметь геометрический скос угла
  через `clip-path` (5px, правый нижний угол кнопки).
- **Без теней** — `box-shadow: none !important` глобально; глубина передаётся
  только сменой поверхности (`--bg-canvas → --bg-surface → --bg-elevated`).

## 2. Палитра (web/src/styles/theme.css)

Две приглушённые низкоконтрастные темы, переключение через
`document.documentElement.dataset.theme`:

| Тема | Поверхности | Назначение |
|---|---|---|
| `stone` (по умолчанию) | `#DAD7D0 / #E2DFD9 / #EAE7E1` | Тёплый бетон / известняк — светлая рабочая тема |
| `ash` | `#222325 / #282A2C / #2F3134` | Матовый графит / сланец — тёмная тема |

Правила:
- Запрещены чистый белый `#FFFFFF`, чистый чёрный `#000000`, кислотные цвета
  (насыщенность S ≤ 22%).
- Семантические тона — десатурированные: шалфей `--tone-positive`,
  охра `--tone-caution`, терракота `--tone-critical`, сизо-серый
  `--tone-neutral` (+ пары `*-bg` для подложек).
- В `.tsx`-компонентах захардкоженные hex/rgb цвета запрещены — только
  переменные из `theme.css`.
- Фокус — не браузерное кольцо: открытые угловые скобки `--focus-bracket`
  через `::before/::after`; выделение текста — `--selection-bg/--selection-ink`.

## 3. Типографика

- Единый спокойный гротеск: `--font-sans: 'Inter', -apple-system, 'Segoe UI', Roboto, Arial, sans-serif`.
- Числовая дисциплина: таблицы, таймкоды, проценты, суммы —
  `font-variant-numeric: tabular-nums slashed-zero`.
- Верхний регистр и межбуквенный разряд (`letter-spacing: 0.04em`) — для
  кнопок, заголовков колонок и навигации (11–12px).

## 4. Собственные изображения-глифы (28 шт.)

Никаких эмодзи и сторонних иконочных библиотек. Все индикаторы —
детерминированно сгенерированные изображения (генератор
`tools/ui/generate_brutalist_glyphs.py`: чистый Python `struct + zlib`, без
внешних зависимостей): `.png` 48×48 (`@2x`) + `.svg` 24×24 в
`web/public/assets/glyphs/`, штрих `#353431`/`#B8B6B0`, прозрачный фон,
строгая геометрия (перекрестия, засечки, ступенчатые диаграммы).

Группы: `nav-*` (8 пунктов навигации), `role-manager`/`role-client`,
`sentiment-pos/neu/neg`, `status-alert/ok/pii`, `channel-call/crm/mail/chat/meet`,
`ctrl-play/pause/upload/copy/sort-asc/sort-desc/theme`.

Рендер — только через `<BrutalistGlyph />` (`<img>` c `image-rendering:
crisp-edges`); в теме `ash` применяется мягкая инверсия яркости.

## 5. Контролы (web/src/styles/controls.css)

- `<SlabButton>` — прямоугольная плашка со скошенным правым нижним углом,
  боковой 2px планкой при наведении, техническим индексом (`indexTag`).
- `<RailToggle>` — механическая рельса с квадратным ползунком и текстом
  `ВКЛ / ВЫКЛ` (слайдер ПДн, настройки, чипы фильтров).
- `<StepSelect>` — кастомный селектор с 1px-сеткой пунктов (без нативного
  меню ОС); `<SegmentedMatrix>` — лента стыкованных ячеек для 2–4 режимов.
- `<MeterBar>` — дискретная 10-сегментная шкала вместо цветных «пилюль».
- Голые `<button>`/`<select>` глобально стилизованы под систему (controls.css),
  чтобы ни один элемент не выглядел браузерно-дефолтным.

## 6. Каркас

- **System Header Bar** (44px): бренд `ПОЛИЛОГ // РЕЧЕВАЯ АНАЛИТИКА`, телеметрия,
  кнопка загрузки записи, переключатель темы `STONE ⇄ ASH` (текстом, без стрелок).
- **Навигационная колонка** (220px): пункты вплотную, сквозные 1px линии,
  двузначные индексы `01..08`, активный пункт — `--bg-selected` + полоса 4px.
- KPI — стыкованные ячейки одной полосы с кодами `M-01 // …`; таблицы —
  `border-collapse: collapse`, hover — `--bg-elevated`.
